🚀 Railway Deployment Guide (Kostenlos & Professionell)

Dieses Tutorial hilft dir, deinen Shop auf Railway.app zu hosten. Wir haben das Projekt so vorbereitet, dass es automatisch migriert und stabil läuft.

1. Vorbereitung (Lokal)

Stelle sicher, dass alle Änderungen gespeichert sind. Ich habe bereits folgende Dateien für dich erstellt:
  • Dockerfile: Konfiguriert den Container.
  • start.sh: Führt migrate und collectstatic automatisch beim Start aus.
  • requirements.txt: Enthält jetzt auch gunicorn und whitenoise.

2. GitHub Repository erstellen

1. Erstelle ein neues privates Repository auf GitHub.
2. Lade deinen Code hoch (git add ., git commit, git push).
⚠️ Wichtig: Deine db.sqlite3 und .env werden durch die .gitignore ignoriert. Das ist gut so! Wir setzen die Variablen gleich in Railway.

3. Deployment auf Railway

1. Gehe auf railway.app und logge dich mit GitHub ein.
2. Klicke auf + New Project -> Deploy from GitHub repo.
3. Wähle dein Repository aus.
4. Railway erkennt das Dockerfile automatisch.

4. Variablen setzen (Wichtig!)

Klicke in Railway auf dein Projekt -> Variables und füge folgende hinzu: 
DEBUG = False
SECRET_KEY = (Dein geheimer Schlüssel)
ALLOWED_HOSTS = *
PYTHON_VERSION = 3.11
Railway vergibt den Port automatisch über die Variable $PORT, die ich bereits im Start-Skript eingebaut habe.

5. Domain erhalten

1. Gehe zu Settings -> Networking.
2. Klicke auf Generate Domain.
3. Deine Website ist nun unter https://dein-projekt.up.railway.app erreichbar!

✅ Warum ist das jetzt besser?

  • Automatisches Migrate: Das System führt python manage.py migrate bei jedem Start selbst aus.
  • Gunicorn: Wir nutzen nicht mehr den Test-Server, sondern einen echten Web-Server für Production.
  • WhiteNoise: Deine Bilder und CSS-Dateien werden nun auch auf Railway korrekt geladen.

6. Kostenlos hosten

Railway bietet ein Free Tier (Hobby Plan) an. Solange dein Projekt innerhalb der Limits bleibt (Trial Credits), ist es kostenlos. Für dauerhaftes kostenloses Hosting ohne Kreditkarte sind Dienste wie Render.com oder Fly.io Alternativen, Railway ist jedoch am einfachsten zu bedienen.
